# Strategy: engineer the non‑properness first, then fight for the Jacobian condition

## 0. The structural reformulation I'd build everything around

A counterexample $F:\mathbb{C}^n\to\mathbb{C}^n$ is étale, quasi-finite, and (by your observation) necessarily **non-proper** and **non-injective** (Ax–Grothendieck kills injective candidates). Apply Zariski's Main Theorem: $F$ factors as

$$\mathbb{C}^n \;\hookrightarrow\; W \;\xrightarrow{\ \pi\ }\; \mathbb{C}^n$$

where $\pi$ is **finite** of degree $d\ge 2$ ($W$ = normalization of the target in the function field extension) and the first arrow is an open immersion. Since $F$ is étale, the source $\mathbb{C}^n$ sits inside $W$ **avoiding the entire ramification locus** of $\pi$. In Kaliman–Zaidenberg language: the source is an **affine modification** of $W$. So the hunt is equivalent to:

> **Find a finite branched cover $\pi: W\to\mathbb{C}^n$, $\deg \pi = d\ge 2$, and a closed subset $E\subset W$ containing $\mathrm{Ram}(\pi)$, such that $W\setminus E\cong \mathbb{C}^n$.**

This is exactly the Danielewski/modification world: you're gluing an affine space out of a branched cover by cutting out the branching and the "wrong" sheets, which is what fibrations like $x^kz=p(y)$ do over the doubled line. The non-properness is now not an accident but the definition: $E$ maps into the Jelonek set $A_F$.

## 1. The constraint ledger (compute this before searching)

These are filters every candidate must pass; encode them as automatic checks.

- **Units obstruction.** $W$ is normal affine, $W\setminus E$ affine open $\Rightarrow$ $E$ is pure codimension 1. If $E$ were set-theoretically cut by one function $g$, then $g$ is a nonconstant unit on $W\setminus E$ — impossible on $\mathbb{C}^n$. So **$E$ is a non-principal divisor and $W$ is not factorial**: look at covers with nontrivial class group (singular double/triple covers, $A_k$-type geometry). Caution from a toy computation: for $W=\{t^2=xz\}$, $E=\{t=x=0\}$ is non-principal but $W\setminus E = D(x)$, so $x$ is still a unit. The check must be "no $g\in\mathcal{O}(W)$ with $V(g)=E$ set-theoretically."
- **Galois obstruction (kills $d=2$).** Known result (Campbell): a Keller map with Galois field extension $\mathbb{C}(x)/\mathbb{C}(F)$ is an automorphism. Degree-2 extensions are Galois, so **$d\ge 3$**.
- **Dimension 2 is nearly closed off.** Moh: no counterexample with $\deg \le 100$; Orevkov and Domrina–Orevkov: no counterexample with $\le 4$ sheets. So in $n=2$ you need $d\ge 5$ and enormous degree. **Primary arena: $n=3$, $d=3$.**
- **Jelonek set constraints.** $A_F$ is a hypersurface, uniruled by polynomial curves. Over $\mathbb{C}^n\setminus A_F$, $F$ is a genuine $d$-sheeted covering, so:
  - $\pi_1(\mathbb{C}^n\setminus A_F)$ must admit an index-$d$ subgroup whose cover is $\mathbb{C}^n\setminus F^{-1}(A_F)$;
  - Euler characteristic bookkeeping: $\chi(\mathbb{C}^n\setminus F^{-1}A_F) = d\cdot\chi(\mathbb{C}^n\setminus A_F)$.
  
  This turns the search into: choose a **uniruled hypersurface $A$ with rich $\pi_1$ of complement**, enumerate index-3 subgroups (GAP), and ask whether the corresponding cover completes to the picture in §0.

## 2. The cylinder/cancellation pipeline (my best structural bet for $n=3$)

Why $n=3$ specifically, beyond the ledger: **Zariski cancellation.** Fujita–Miyanishi–Sugie proved $S\times\mathbb{C}\cong\mathbb{C}^3\Rightarrow S\cong\mathbb{C}^2$, which blocks the cheap trick of taking a non-proper étale map from an exotic surface and crossing with $\mathrm{id}_\mathbb{C}$. But **cancellation for $\mathbb{C}^3$ is open in characteristic 0** (and *false* in char $p$, by N. Gupta, using precisely Danielewski/Asanuma-type fibrations). So the pipeline is:

1. Build a smooth affine threefold $X$ with a quasi-finite, étale, non-proper, degree-3 map $X\to\mathbb{C}^3$, where $X$ arises as $W\setminus E$ as in §0 — $X$ contractible, trivial units, trivial ML-invariant, etc., but not obviously $\mathbb{C}^3$.
2. Try to prove $X\times\mathbb{C}\cong\mathbb{C}^4$ via the **Danielewski fiber-product trick** (the same mechanism that makes $\{xz=y^2-1\}\times\mathbb{C}\cong\{x^2z=y^2-1\}\times\mathbb{C}$): if $X$ is fibered over a base with a "doubled/tripled" non-separated locus, cylinders often trivialize *explicitly*.
3. If (2) succeeds, $X\times\mathbb{C}\to\mathbb{C}^3\times\mathbb{C}$ is a degree-3 étale non-proper Keller map of $\mathbb{C}^4$. Done. (Or, if $X\cong\mathbb{C}^3$ outright, done in dimension 3.)

Even a failure here is publishable: it either proves cancellation-type rigidity for these $X$, or produces new exotic candidates.

## 3. Concrete first steps (in order)

**Week 1–2: tooling.**
- Implement Jelonek's effective algorithm for the non-properness set $S_F$ (Gröbner-based, via the graph closure in $\mathbb{P}^n\times\mathbb{C}^n$) in Macaulay2/Singular.
- Implement geometric-degree computation: numerically, count fiber points of $F(z)=w$ for random $w$ with monodromy in `HomotopyContinuation.jl`. This is the counterexample detector: **Keller + generic fiber $\ge 2$ points = win.**
- Rees-algebra code for affine modifications; `normal.lib` for building $W$ as integral closures in explicit cubic field extensions.

**Week 2–4: calibration on known geometry.**
- Compute $S_F$, degree, and the ZMT factorization for the substrate maps: $(x,y)\mapsto(x,1+xy)$, Danielewski fibrations $x^kz=p(y)$, the étale self-covers of $\mathbb{C}^*\times\mathbb{C}$ like $(x,y)\mapsto(x^2,xy)$ (a proper étale degree-2 cover — instructive contrast), and the **complexified Pinchuk map** (which is *built* on the modification $t=xy-1$; it's the closest existing object to what we want and shows exactly how the substrate feeds a Newton-polygon cancellation for the Jacobian).

**Month 2–3: two parallel searches.**

*(a) Top-down (covering-space search).* Pick candidate asymptotic hypersurfaces $A\subset\mathbb{C}^3$ that are uniruled and have nonabelian $\pi_1(\mathbb{C}^3\setminus A)$ (generic-plane-section + Zariski–van Kampen to compute it; start with cones over plane curves with rich complements). Enumerate index-3 subgroups; for each, construct $W$ = normalization of $\mathbb{C}^3$ in the corresponding cubic extension; locate $\mathrm{Ram}(\pi)$; search for non-principal $E\supseteq \mathrm{Ram}(\pi)$ with $W\setminus E$ affine; then run the "is it $\mathbb{C}^3$?" battery: units, class group, topology (χ, contractibility via equivariant/Morse-type computations), ML invariant via LND search, and attempted explicit coordinates. Feed survivors to pipeline §2.

*(b) Bottom-up (ansatz search).* Work in modification-adapted coordinates on the source: $u=1+xy$, and take ansätze $F=(f,g,h)$ with $f,g,h\in\mathbb{C}[x,u,z]$-shaped supports chosen so that $\det JF$ telescopes: the substrate contributes a factor $x$ which must be cancelled by design of the Newton polytopes (this is the Pinchuk mechanism, but targeting $\det JF\equiv 1$ instead of $>0$). Impose $\det JF - 1 \equiv 0$ as a polynomial system in the coefficients; solve with Gröbner bases / numerical irreducible decomposition; for every solution component, sample maps and run the degree detector. Normalize by pre/post-composition with tame automorphisms to cut the search space.

**Ongoing: negative-result harvesting.** Every dead end should be converted into a lemma ("no counterexample with $A_F$ a cylinder over a cuspidal cubic," "$W$ with only $A_1$ singularities cannot occur," ...). If the constraint ledger starts proving emptiness in whole strata, that's evidence toward the conjecture — which is the honest dual outcome of a counterexample hunt.

## 4. Realistic self-assessment

The single most likely failure point is step §2(2)/§3(a): candidates $X$ that pass every computable test but resist both an isomorphism to $\mathbb{C}^3$ and a disproof — i.e., the hunt reduces JC-instances to hard cancellation/exotic-space questions. That's still the right place to be stuck: it converts a diffuse open problem into specific, checkable geometry, and the char-$p$ Gupta examples give a template for what a miracle would look like in characteristic 0.
